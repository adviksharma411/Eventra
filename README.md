# Eventra - Event Management and Ticketing System

Python + MySQL project by Advik and Aayushi.

## Setup
1. Install Python 3 and MySQL
2. Run `pip install mysql-connector-python`
3. Run schema.sql and seed_data.sql in MySQL
4. Copy db_config_example.py to db_config.py and fill in your MySQL password
5. Run `python3 main.py`
